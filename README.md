# 勘定科目 分類ツール

勘定科目マスタ(Excel)から分類ツリーを作り、検査して、Dify のワークフロー(DSL)まで作るツールです。

- **公開ページ: https://okadamasayuki.github.io/kanjo-tool/**
  開くとそのままツールが立ち上がります(インストール・ダウンロード不要)

## ファイル

- `index.html` … ツール本体。公開ページのURLを開くとこれが表示されます
- `kanjo-tool.html` … 同じ中身(以前のリンクを残すため。どちらを開いても同じです)

## 使い方

上のURLを開くだけです。ブラウザの中だけで動きます。
手元に保存して使いたい場合は、ページを「名前を付けて保存」すれば
ダブルクリックで同じように動きます(1ファイルで完結しています)。

## 注意

- **処理はすべてブラウザの中だけで行われ、読み込んだファイルはどこにも送信されません。**
  外部との通信を行うコードは含まれていません(ネットワークを切断した状態でも全機能が動きます)。
- 本体は自己完結型の1ファイルHTMLです。**整形・minify・分割は行わないでください**(壊れます)。
- このリポジトリは公開です。**業務データ(勘定科目マスタ・分類ツリーなど)は置かないでください。**
